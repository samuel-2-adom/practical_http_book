Headers

Headers are metadata that travel alongside every HTTP request and response. They're how the client and server communicate things like "what format is this data?" and "who are you?"

🎯 What you'll learn
  • What headers are and where they live in a request/response
  • The headers you'll use most often as an API client
  • How to send headers with Python's requests library
  • How to read response headers

5.1 What Are Headers?

Every HTTP request and response has two parts: headers and a body.

The body is the actual content — the JSON data, the HTML, the file. Headers are the metadata that describe the message itself: what format the body is in, who sent it, what kind of response is acceptable, and so on.

HTTP Request ───────────────────────────────── GET /users HTTP/1.1 Host: api.example.com Authorization: Bearer abc123 Accept: application/json User-Agent: MyApp/1.0 ← headers end here (blank line) ← body starts (empty for GET)
HTTP Response ───────────────────────────────── HTTP/1.1 200 OK Content-Type: application/json Content-Length: 248 X-RateLimit-Remaining: 58 ← headers end here (blank line) {"id": 42, "name": "Samuel"} ← body

Headers are key-value pairs, separated by a colon. They're case-insensitive (so Content-Type and content-type are the same), but by convention they use Title-Case.

5.2 Important Request Headers

Authorization

Used to send credentials — an API key or token — so the server knows who you are.

Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
Authorization: Basic dXNlcjpwYXNz
Authorization: Token abc123def456

We'll cover authentication in depth in Chapter 10. For now just know this header exists and carries credentials.

Content-Type

Tells the server what format the request body is in. Required when sending data.

Content-Type: application/json        # you're sending JSON
Content-Type: application/x-www-form-urlencoded  # form data
Content-Type: multipart/form-data     # file upload
💡 Automatic with requests

When you use requests.post(..., json=data), the library automatically sets Content-Type: application/json. You only need to set it manually in unusual situations.

Accept

Tells the server what format you want back.

Accept: application/json   # please respond with JSON
Accept: text/html          # please respond with HTML

Most APIs return JSON regardless, but some can return multiple formats and use this header to decide.

User-Agent

Identifies the client making the request. Your browser sends something like Mozilla/5.0.... Python's requests library sends python-requests/2.x.x.

Some APIs check this — they might block unknown user agents or require you to identify your application. You can set a custom one:

User-Agent: MyPythonApp/1.0

5.3 Important Response Headers

Content-Type

Tells you what format the response body is in. Always check this if you're not sure what you got back.

Content-Type: application/json; charset=utf-8
Content-Type: text/html; charset=utf-8
Content-Type: image/png

X-RateLimit-* headers

Many APIs include headers that tell you about your rate limit usage:

X-RateLimit-Limit: 100        # max requests per period
X-RateLimit-Remaining: 73     # how many you have left
X-RateLimit-Reset: 1700000000 # when it resets (Unix timestamp)

Retry-After

Sent with a 429 (Too Many Requests) to tell you how long to wait before retrying:

HTTP/1.1 429 Too Many Requests
Retry-After: 60   # wait 60 seconds

5.4 Sending Headers in Python

Pass headers as a dictionary to any requests call:

import requests

headers = {
    "Authorization": "Bearer my_token_here",
    "Accept": "application/json",
}

response = requests.get(
    "https://api.example.com/users",
    headers=headers
)

5.5 Reading Response Headers in Python

Response headers come back as a dictionary-like object:

response = requests.get("https://api.example.com/data")

# Access a specific header
content_type = response.headers["Content-Type"]
print(content_type)
# "application/json; charset=utf-8"

# Check rate limit remaining (if the API sends it)
remaining = response.headers.get("X-RateLimit-Remaining")
print(remaining)
# "73"

# Print all response headers
for key, value in response.headers.items():
    print(f"{key}: {value}")
⚠️ Header values are always strings

Even if a header value looks like a number — like X-RateLimit-Remaining: 73 — it comes back as the string "73", not the integer 73. Use int() to convert if you need to do arithmetic with it.

📝 Exercises
Exercise 1 — Which header tells the server what format your request body is in?
  • A Accept
  • B Content-Type
  • C Authorization
Content-Type on a request tells the server what format you're sending. Accept tells the server what format you want back. Authorization carries credentials.
Exercise 2 — How do you send custom headers with the requests library?
  • A requests.get(url, header="Authorization: Bearer token")
  • B requests.get(url).set_header("Authorization", "Bearer token")
  • C requests.get(url, headers={"Authorization": "Bearer token"})
Pass a dictionary to the headers= parameter. The key is the header name, the value is the header value. Multiple headers go in the same dictionary.
Exercise 3 — You read response.headers["X-RateLimit-Remaining"] and get "5". You want to check if it's less than 10. What must you do first?
  • A Convert it to an integer with int()
  • B Nothing — "5" < 10 works fine in Python
  • C Use float() instead
Header values are always strings. Comparing a string like "5" to an integer 10 in Python raises a TypeError. Use int(response.headers["X-RateLimit-Remaining"]) < 10.
🧠 Checkpoint

Write the Python code to make a GET request to https://api.example.com/data with two headers: an Authorization header set to "Bearer abc123", and an Accept header set to "application/json". Then print the response's Content-Type header.

import requests

headers = {
    "Authorization": "Bearer abc123",
    "Accept": "application/json",
}

response = requests.get("https://api.example.com/data", headers=headers)
print(response.headers["Content-Type"])
📌 What to remember

· Headers are metadata sent alongside requests and responses

· Authorization — your credentials

· Content-Type — format of the body being sent

· Accept — format you want back

· Send with headers={...} · Read with response.headers["Name"]

· Header values are always strings
