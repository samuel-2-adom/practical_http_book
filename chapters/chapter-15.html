Real API: GitHub

GitHub's API is one of the best-documented in the world. In this chapter you'll use it to search repos, read user profiles, and handle pagination — everything you need for real API work.

🎯 What you'll learn
  • Using a token-authenticated API
  • Navigating GitHub's API documentation
  • Searching repositories and reading user data
  • Pagination — fetching more than one page of results
💡 Setup: GitHub Personal Access Token

GitHub's API works without auth (rate limited to 60 requests/hour) or with a Personal Access Token (5,000/hour). To get one: GitHub → Settings → Developer settings → Personal access tokens → Generate new token (classic). Select public_repo scope. Store as export GITHUB_TOKEN="ghp_yourtoken".

15.1 GitHub API Basics

Base URL: https://api.github.com

Auth header: Authorization: Bearer YOUR_TOKEN

import os, requests

token = os.environ.get("GITHUB_TOKEN")
headers = {"Authorization": f"Bearer {token}"} if token else {}

BASE = "https://api.github.com"

15.2 Fetching a User's Profile

response = requests.get(f"{BASE}/users/python", headers=headers)
user = response.json()

print(user["login"])         # "python"
print(user["public_repos"])  # number of public repos
print(user["followers"])     # follower count

15.3 Searching Repositories

response = requests.get(
    f"{BASE}/search/repositories",
    headers=headers,
    params={
        "q": "python api tutorial",
        "sort": "stars",
        "order": "desc",
        "per_page": 5,
    }
)

data = response.json()
print(f"Total results: {data['total_count']}")

for repo in data["items"]:
    print(f"  ⭐ {repo['stargazers_count']:,} — {repo['full_name']}")
    print(f"     {repo.get('description', 'No description')}")

15.4 Pagination

GitHub returns max 100 results per page. For more, loop through pages:

def get_all_repos(username, max_pages=3):
    all_repos = []
    for page in range(1, max_pages + 1):
        response = requests.get(
            f"{BASE}/users/{username}/repos",
            headers=headers,
            params={"per_page": 30, "page": page}
        )
        repos = response.json()
        if not repos:   # empty page = no more results
            break
        all_repos.extend(repos)
    return all_repos

repos = get_all_repos("python")
print(f"Fetched {len(repos)} repos")

15.5 Checking Rate Limits

response = requests.get(f"{BASE}/rate_limit", headers=headers)
limits = response.json()["rate"]
print(f"Requests remaining: {limits['remaining']}/{limits['limit']}")
📝 Exercises
Exercise 1 — Why does the GitHub search endpoint return results under data["items"] instead of directly as a list?
  • A It's a bug in the GitHub API
  • B The response also includes metadata like total_count, so items is wrapped in an object
  • C GitHub uses XML, not JSON
Search endpoints typically return an envelope object: {"total_count": 1234, "incomplete_results": false, "items": [...]}. This lets them include metadata alongside the results. Always check the API docs for the response structure.
Exercise 2 — Without authentication, GitHub limits you to how many requests per hour?
  • A 1,000
  • B 500
  • C 60
Unauthenticated GitHub API requests are limited to 60/hour. Authenticated requests get 5,000/hour. This is why getting a token matters for serious work.
🧠 Final Project: GitHub Repo Finder

Build a program that takes a GitHub username as input, fetches their public repos, sorts them by star count, and prints the top 5 with name, stars, and description. Add error handling for non-existent users.

import os, requests

token = os.environ.get("GITHUB_TOKEN")
headers = {"Authorization": f"Bearer {token}"} if token else {}
BASE = "https://api.github.com"

username = input("GitHub username: ").strip()

try:
    response = requests.get(
        f"{BASE}/users/{username}/repos",
        headers=headers,
        params={"per_page": 100},
        timeout=10
    )
except requests.exceptions.RequestException as e:
    print(f"Connection error: {e}")
    exit()

if response.status_code == 404:
    print(f"User '{username}' not found.")
    exit()
elif not response.ok:
    print(f"Error: {response.status_code}")
    exit()

repos = sorted(response.json(),
               key=lambda r: r["stargazers_count"],
               reverse=True)

print(f"\nTop repos for @{username}:\n")
for repo in repos[:5]:
    stars = repo["stargazers_count"]
    desc  = repo.get("description") or "No description"
    print(f"  ⭐ {stars:,}  {repo['name']}")
    print(f"        {desc}\n")
