Glossary

Every term used in this book, defined plainly.

API
Application Programming Interface. A defined way for programs to communicate with each other over a network, usually using HTTP and JSON.
API Key
A secret string that identifies you to an API. Sent with every request, usually in a header. Never hardcode in source files.
Authentication
Proving your identity to a server. Common methods: API key, Bearer token, Basic auth.
Bearer Token
An auth token sent in the Authorization header: Authorization: Bearer TOKEN.
Body
The data payload of an HTTP request or response. GET requests have no body; POST/PUT/PATCH requests typically do.
Client
Anything that makes HTTP requests: a browser, a mobile app, or a Python program.
CRUD
Create, Read, Update, Delete. Maps to POST, GET, PUT/PATCH, DELETE.
Endpoint
A specific URL where an API provides a resource or operation. E.g., https://api.example.com/users.
Environment Variable
A variable set outside your code, used to pass secrets like API keys safely.
Header
Metadata sent alongside HTTP requests and responses. Key-value pairs describing format, auth, rate limits, etc.
HTTP
HyperText Transfer Protocol. The rules governing how clients and servers exchange requests and responses.
HTTPS
HTTP + TLS encryption. Keeps data private in transit. Always use https:// for API calls.
Idempotent
An operation that produces the same result whether done once or many times. GET is idempotent; POST is not.
JSON
JavaScript Object Notation. The text format most APIs use for structured data. Maps to Python dicts and lists.
Method
The verb of an HTTP request: GET, POST, PUT, PATCH, DELETE.
Pagination
Breaking large result sets into pages, controlled with page and per_page parameters.
Path Parameter
A variable embedded in the URL path identifying a resource. The 42 in /users/42.
Query Parameter
A key=value pair after the ? in a URL, used to filter or modify a request.
Rate Limit
A cap on how many API requests you can make per time period. Exceeded limits return 429.
Request
A message sent from a client to a server asking for something or sending data.
Resource
A thing in a REST API: a user, a post, a product. Each has its own URL.
Response
The server's reply to a request. Contains a status code, headers, and usually a body.
REST
Representational State Transfer. A style of API design that uses HTTP methods and resource URLs predictably.
Server
A program that receives HTTP requests and sends responses.
Status Code
A three-digit number indicating success (2xx), redirect (3xx), client error (4xx), or server error (5xx).
TLS
Transport Layer Security. The encryption protocol that makes HTTPS secure.
Timeout
A limit on how long to wait for a server response. Set with timeout= in requests.
Token
A credential used for authentication. See Bearer Token, API Key.
URL
Uniform Resource Locator. The address of a resource: scheme://host:port/path?query#fragment.
URL Encoding
Converting special characters to %XX hex codes. requests handles this automatically via params=.
