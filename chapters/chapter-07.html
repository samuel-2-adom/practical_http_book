GET Requests

GET is the method you'll use more than any other. This chapter covers everything about making GET requests — including how to pass parameters, inspect what was sent, and handle the response properly.

🎯 What you'll learn
  • How to make GET requests to real URLs
  • How to pass query parameters using params=
  • How to inspect the full request that was sent
  • How to work with the response data

7.1 Basic GET

You've already seen the basics. Let's make it concrete with a real public API — JSONPlaceholder, a free fake REST API for testing:

import requests

# Get a list of posts
response = requests.get("https://jsonplaceholder.typicode.com/posts")

print(response.status_code)   # 200
posts = response.json()
print(type(posts))             # <class 'list'>
print(len(posts))              # 100
print(posts[0])               # {'userId': 1, 'id': 1, 'title': '...', 'body': '...'}

7.2 Getting a Specific Resource

To get a single item, use a path parameter in the URL:

# Get post with ID 5
response = requests.get("https://jsonplaceholder.typicode.com/posts/5")

post = response.json()
print(post["title"])   # the title of post 5

A common pattern is building the URL dynamically:

post_id = 5
url = f"https://jsonplaceholder.typicode.com/posts/{post_id}"
response = requests.get(url)

7.3 Query Parameters with params=

For filtering or searching, pass query parameters as a dictionary using the params= argument. The library builds the correct URL for you:

# Get posts by user 1
params = {"userId": 1}
response = requests.get(
    "https://jsonplaceholder.typicode.com/posts",
    params=params
)

# The actual URL sent was:
# https://jsonplaceholder.typicode.com/posts?userId=1
print(response.url)   # confirms the URL that was used

posts = response.json()
print(len(posts))  # 10 (only user 1's posts)
🔵 Always use params=, never build query strings manually

Don't do this:

url = f"https://api.example.com/search?q={query}&page={page}"

Do this:

params = {"q": query, "page": page}
requests.get(url, params=params)

The library handles URL encoding automatically. Manual string building breaks when values contain spaces or special characters.

7.4 Inspecting the Request That Was Sent

The response.request attribute lets you see the actual request that was made:

params = {"q": "python tutorial", "page": 2}
response = requests.get("https://api.example.com/search", params=params)

print(response.request.url)
# https://api.example.com/search?q=python+tutorial&page=2

print(response.request.method)
# GET

print(dict(response.request.headers))
# Shows all headers that were sent

7.5 A Real-World Pattern

Here's the pattern you'll use in almost every real program:

import requests

def get_user_posts(user_id):
    """Fetch posts for a specific user."""
    url = "https://jsonplaceholder.typicode.com/posts"
    params = {"userId": user_id}

    response = requests.get(url, params=params)

    if response.status_code == 200:
        return response.json()
    else:
        print(f"Error: {response.status_code}")
        return []

posts = get_user_posts(3)
print(f"Found {len(posts)} posts")
for post in posts[:3]:
    print(f" - {post['title']}")
📝 Exercises — Use JSONPlaceholder
Exercise 1 — What's wrong with this code?
response = requests.get("api.example.com/users")
  • A Nothing — it works fine
  • B The URL is missing the scheme (https://)
  • C GET requires a params= argument
The URL must include the scheme. Without https://, requests doesn't know how to connect. It will raise a MissingSchema exception. Always write https://api.example.com/users.
Exercise 2 — You want to request /posts?userId=2&_limit=5. Which code is correct?
  • A requests.get(url + "?userId=2&_limit=5")
  • B requests.get(url, query={"userId": 2, "_limit": 5})
  • C requests.get(url, params={"userId": 2, "_limit": 5})
Option C — the params= keyword argument accepts a dictionary and builds the query string automatically. Option A works but breaks with special characters. Option B uses the wrong keyword (query doesn't exist).
Exercise 3 — How do you confirm exactly which URL was sent to the server?
  • A response.url or response.request.url
  • B response.sent_url
  • C requests.last_url()
response.url shows the final URL (after any redirects). response.request.url shows the URL of the request as it was prepared and sent.
🧠 Mini-Project: Post Explorer

Write a program that:

  1. 1. Asks the user for a userId (1–10)
  2. 2. Fetches their posts from https://jsonplaceholder.typicode.com/posts
  3. 3. Prints the number of posts found
  4. 4. Prints the title of each post
import requests

user_id = input("Enter a userId (1-10): ")

response = requests.get(
    "https://jsonplaceholder.typicode.com/posts",
    params={"userId": user_id}
)

if response.ok:
    posts = response.json()
    print(f"\nFound {len(posts)} posts for user {user_id}:\n")
    for post in posts:
        print(f" - {post['title']}")
else:
    print(f"Error: {response.status_code}")
