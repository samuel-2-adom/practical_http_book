Install

pip install requests

Making Requests

import requests

response = requests.get(url)
response = requests.get(url, params={"key": "val"})
response = requests.get(url, headers={"Authorization": "Bearer TOKEN"})
response = requests.get(url, timeout=10)

response = requests.post(url, json={"key": "val"})
response = requests.post(url, data={"key": "val"})

response = requests.put(url, json=data)
response = requests.patch(url, json={"field": "value"})
response = requests.delete(url)

Response Object

response.status_code        # int: 200, 404, etc.
response.ok                 # True for 2xx status codes
response.text               # body as string
response.content            # body as bytes
response.json()             # parse JSON to dict/list
response.headers            # response headers (dict-like)
response.url                # final URL after redirects
response.raise_for_status()  # raise HTTPError on 4xx/5xx

Error Handling Pattern

try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
    data = response.json()
except requests.exceptions.HTTPError:
    print(f"HTTP {response.status_code}")
except requests.exceptions.ConnectionError:
    print("No connection")
except requests.exceptions.Timeout:
    print("Timed out")
except requests.exceptions.RequestException as e:
    print(f"Error: {e}")

Authentication

import os
api_key = os.environ.get("MY_API_KEY")   # SAFE — not in code

headers = {"Authorization": f"Bearer {api_key}"}
response = requests.get(url, headers=headers, auth=("user", "pass"))

Status Codes to Know

200 OK success, data returned 201 Created resource created (POST) 204 No Content success, nothing returned 400 Bad Request malformed / invalid data 401 Unauthorized not authenticated 403 Forbidden authenticated but not allowed 404 Not Found resource doesn't exist 429 Rate Limited too many requests 500 Server Error server crashed (not your fault) 503 Unavailable server down, retry later

URL Structure

https://api.example.com:443/users/42?sort=name&limit=10 schema host port path query string

REST: Method + URL = Action

GET /items list all GET /items/5 get one POST /items create PUT /items/5 replace PATCH /items/5 partial update DELETE /items/5 delete

JSON to Python

JSON object dict JSON array list string str number int / float true/false True / False null None

Safe Navigation

data.get("key")                     # None if missing
data.get("key", "default")         # default if missing
data.get("a", {}).get("b")        # nested safe
data["list"][0]["key"]            # list item key

Environment Variables

export MY_KEY="value"              # Mac/Linux terminal
set MY_KEY=value                   # Windows terminal

key = os.environ.get("MY_KEY")    # None if not set
key = os.environ["MY_KEY"]       # KeyError if not set
