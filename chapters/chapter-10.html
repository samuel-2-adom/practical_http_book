Authentication

Most real APIs require authentication. This chapter covers the common patterns and — crucially — how to keep your secrets safe.

🎯 What you'll learn
  • Why APIs require authentication
  • The three most common auth patterns: API key, Bearer token, Basic auth
  • How to store secrets safely using environment variables
  • How to send credentials in headers

10.1 Why Authentication Exists

Without authentication, anyone could call your API and:

  • · Read data they shouldn't see
  • · Create, update, or delete records
  • · Hammer the server with unlimited requests

Authentication solves this by requiring every caller to prove who they are before the server responds.

10.2 API Keys

The simplest pattern. You sign up for the API, it gives you a unique key, and you send that key with every request.

API keys are most commonly sent in a header:

import requests

headers = {
    "Authorization": "Bearer YOUR_API_KEY"
}

response = requests.get(
    "https://api.example.com/data",
    headers=headers
)

Some older APIs send the key as a query parameter instead:

params = {"api_key": "YOUR_KEY"}
# → https://api.example.com/data?api_key=YOUR_KEY
⚠️ Don't put API keys in query strings if you can avoid it

Query string parameters appear in server logs and browser history. Headers are safer. Use a query parameter only when the API requires it.

10.3 Bearer Tokens

Bearer tokens are the most common modern pattern. You authenticate once (login) and receive a token. Then you send that token with subsequent requests:

headers = {
    "Authorization": f"Bearer {token}"
}
response = requests.get(url, headers=headers)

The word "Bearer" is part of the header format — it means "whoever holds (bears) this token is authorized."

10.4 Basic Authentication

Some older APIs use HTTP Basic Auth — a username and password encoded in the request. The requests library handles this cleanly:

response = requests.get(
    "https://api.example.com/private",
    auth=("my_username", "my_password")
)

10.5 🔐 Never Hardcode Secrets

This is critically important. Never write your API key directly in your code:

# ❌ NEVER DO THIS
api_key = "sk-abc123secretkey456def"  # WRONG

If you push this code to GitHub, your key is exposed permanently — even if you delete it later, it's in the git history.

Instead, use environment variables:

import os
import requests

api_key = os.environ.get("MY_API_KEY")
if not api_key:
    raise ValueError("MY_API_KEY not set")

headers = {"Authorization": f"Bearer {api_key}"}
response = requests.get(url, headers=headers)

10.6 Setting Environment Variables

In your terminal (lasts for the session):

export MY_API_KEY="your-actual-key-here"   # Mac/Linux
set MY_API_KEY=your-actual-key-here        # Windows

Or create a .env file and use the python-dotenv package:

# .env file (never commit this to git!)
MY_API_KEY=your-actual-key-here
# .gitignore — add this line
.env
from dotenv import load_dotenv
load_dotenv()
api_key = os.environ["MY_API_KEY"]
📝 Exercises
Exercise 1 — What does "Bearer" mean in "Authorization: Bearer TOKEN"?
  • A It's the username
  • B It's a random word with no meaning
  • C It's an auth scheme — whoever holds this token is authorized
"Bearer" is the authentication scheme type. It means "the bearer (holder) of this token has permission to access the resource." It's part of the HTTP Authorization header format.
Exercise 2 — Why should you never hardcode an API key in your Python file?
  • A It makes the code run slower
  • B If the code is shared or pushed to git, the key is exposed
  • C Python can't read string literals that look like keys
API keys are like passwords. If your code is on GitHub (even a private repo that later becomes public), or shared with anyone, the key is compromised. Use environment variables so the key lives outside the code.
🧠 Checkpoint

Write a function make_authenticated_request(url) that reads an API key from the environment variable API_KEY and sends it as a Bearer token header. It should return the JSON response if successful, or raise an error if the key isn't set.

import os
import requests

def make_authenticated_request(url):
    api_key = os.environ.get("API_KEY")
    if not api_key:
        raise ValueError("API_KEY environment variable not set")

    headers = {"Authorization": f"Bearer {api_key}"}
    response = requests.get(url, headers=headers)

    if response.ok:
        return response.json()
    else:
        raise Exception(f"Request failed: {response.status_code}")
