Error Handling

Real programs talk to real networks — and real networks fail. This chapter teaches you to write code that handles failure gracefully.

🎯 What you'll learn
  • The two categories of errors: HTTP errors and network errors
  • How to use raise_for_status()
  • How to handle timeouts and connection failures
  • Writing robust error handling for real programs

11.1 Two Kinds of Failure

When making HTTP requests, things can go wrong in two fundamentally different ways:

Network errors HTTP errors ──────────────────────────────────────── The request never The request reached reached the server the server, but the (no internet, bad server said "no" URL, server down) (4xx, 5xx response) raise exceptions return a response with automatically a non-200 status code

11.2 HTTP Errors — raise_for_status()

By default, requests doesn't raise an exception for 4xx/5xx responses. You have to check manually — or use raise_for_status():

response = requests.get("https://httpbin.org/status/404")

# Without raise_for_status: no exception, status_code is 404
print(response.status_code)  # 404 — no error raised

# With raise_for_status:
response.raise_for_status()  # raises HTTPError for 4xx/5xx

Use it in a try/except:

import requests

try:
    response = requests.get("https://httpbin.org/status/404")
    response.raise_for_status()
    data = response.json()
except requests.exceptions.HTTPError as e:
    print(f"HTTP error: {e}")

11.3 Network Errors

If the request can't reach the server at all, you get an exception:

try:
    response = requests.get("https://does-not-exist.example.com")
except requests.exceptions.ConnectionError as e:
    print("Could not connect")

11.4 Timeouts

Never let a request hang forever. Always set a timeout:

try:
    response = requests.get(url, timeout=10)  # 10 seconds
except requests.exceptions.Timeout:
    print("Request timed out")

You can also set separate connect and read timeouts:

timeout=(3, 10)  # 3s to connect, 10s to read

11.5 The Exception Hierarchy

requests.exceptions.RequestException (catch-all) ├── ConnectionError (can't connect) ├── Timeout (took too long) ├── HTTPError (4xx / 5xx response) └── TooManyRedirects (redirect loop)

RequestException is the base class. Catching it catches everything:

try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
    return response.json()
except requests.exceptions.HTTPError as e:
    print(f"HTTP error {response.status_code}: {e}")
except requests.exceptions.ConnectionError:
    print("No connection")
except requests.exceptions.Timeout:
    print("Timed out")
except requests.exceptions.RequestException as e:
    print(f"Unexpected error: {e}")
📝 Exercises
Exercise 1 — Does requests automatically raise an exception when it receives a 404?
  • A Yes — all 4xx and 5xx raise exceptions
  • B No — you must call raise_for_status() or check status_code
  • C Only 5xx raises exceptions; 4xx does not
By default, requests does NOT raise exceptions for error status codes. A 404 or 500 returns a Response object with that status code. You raise the exception yourself with raise_for_status().
Exercise 2 — What does timeout=10 do?
  • A Waits up to 10 minutes for the server to respond
  • B Retries the request 10 times
  • C Raises a Timeout exception if the server doesn't respond within 10 seconds
The timeout is in seconds. If the server hasn't responded within 10 seconds, requests raises a Timeout exception. Without a timeout, a slow or dead server can hang your program indefinitely.
🧠 Checkpoint — Robust Request Function

Write a function safe_get(url) that makes a GET request with a 10-second timeout and returns the JSON data, or None if anything goes wrong (with a descriptive print statement for each error type).

import requests

def safe_get(url):
    try:
        response = requests.get(url, timeout=10)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.HTTPError as e:
        print(f"HTTP error: {response.status_code}")
    except requests.exceptions.ConnectionError:
        print("Connection failed — check your internet")
    except requests.exceptions.Timeout:
        print("Request timed out after 10 seconds")
    except requests.exceptions.RequestException as e:
        print(f"Unexpected error: {e}")
    return None
