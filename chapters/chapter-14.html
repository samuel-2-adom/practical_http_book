Real API: OpenWeather

Everything clicks here. You'll register for a real API key, read real documentation, and build a working weather program that fetches live data.

🎯 What you'll learn
  • How to register for and use a real API key
  • Reading real API documentation
  • Fetching and parsing live weather data
  • Building a complete weather CLI program
💡 Setup required

This chapter uses the OpenWeatherMap API. Sign up free at openweathermap.org/api. Your API key arrives by email and activates within a few minutes. Store it as an environment variable: export OWM_API_KEY="your_key"

14.1 Reading the Documentation

The endpoint we'll use is the Current Weather Data endpoint:

GET https://api.openweathermap.org/data/2.5/weather

Required parameters:
  q      → city name  (e.g. "Accra")
  appid  → your API key
  units  → "metric" (Celsius) or "imperial" (Fahrenheit)

14.2 Making the Request

import os
import requests

api_key = os.environ.get("OWM_API_KEY")

params = {
    "q": "Accra",
    "appid": api_key,
    "units": "metric",
}

response = requests.get(
    "https://api.openweathermap.org/data/2.5/weather",
    params=params
)

print(response.status_code)
print(response.json())

14.3 Understanding the Response

The API returns a rich JSON object. Here's the structure you'll use most:

{
    "name": "Accra",
    "main": {
        "temp": 28.5,
        "feels_like": 31.2,
        "humidity": 78
    },
    "weather": [
        {"description": "scattered clouds"}
    ],
    "wind": {"speed": 4.1}
}

Note that "weather" is a list — always access it with [0].

14.4 Extracting the Data

data = response.json()

city        = data["name"]
temp        = data["main"]["temp"]
feels_like  = data["main"]["feels_like"]
humidity    = data["main"]["humidity"]
description = data["weather"][0]["description"]
wind_speed  = data["wind"]["speed"]

print(f"Weather in {city}")
print(f"  {temp}°C — {description}")
print(f"  Feels like {feels_like}°C, humidity {humidity}%")
print(f"  Wind: {wind_speed} m/s")

14.5 Handling Errors Properly

A 404 from the weather API means the city wasn't found. A 401 means your API key is wrong. Handle both:

if response.status_code == 200:
    data = response.json()
    # ... use the data
elif response.status_code == 404:
    print("City not found. Check the spelling.")
elif response.status_code == 401:
    print("Invalid API key.")
else:
    print(f"Error: {response.status_code}")
🧠 Mini-Project: Weather CLI

Build a complete command-line weather program. The user types a city name; the program fetches and prints the current conditions. Include proper error handling for bad city names and missing API keys. Add the ability to choose Celsius or Fahrenheit.

import os
import requests

def get_weather(city, units="metric"):
    api_key = os.environ.get("OWM_API_KEY")
    if not api_key:
        print("Error: OWM_API_KEY not set")
        return

    try:
        response = requests.get(
            "https://api.openweathermap.org/data/2.5/weather",
            params={"q": city, "appid": api_key, "units": units},
            timeout=10
        )
    except requests.exceptions.RequestException as e:
        print(f"Connection error: {e}")
        return

    if response.status_code == 404:
        print(f"City '{city}' not found.")
        return
    elif response.status_code == 401:
        print("Invalid API key.")
        return
    elif not response.ok:
        print(f"Error: {response.status_code}")
        return

    d = response.json()
    unit_sym = "°C" if units == "metric" else "°F"
    print(f"\nWeather in {d['name']}")
    print(f"  {d['main']['temp']}{unit_sym} — {d['weather'][0]['description']}")
    print(f"  Feels like {d['main']['feels_like']}{unit_sym}")
    print(f"  Humidity: {d['main']['humidity']}%")
    print(f"  Wind: {d['wind']['speed']} m/s")

city = input("Enter city name: ")
unit_choice = input("Units (metric/imperial) [metric]: ") or "metric"
get_weather(city, unit_choice)
