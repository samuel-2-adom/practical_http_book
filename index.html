with Python

You already know Python. Now learn how Python talks to the web — so you can fetch data, call APIs, and build programs that connect to the world outside your machine.

What this book is

This is a hands-on guide to understanding HTTP and using Python's requests library to communicate with web servers and APIs.

It assumes you've already learned Python fundamentals — variables, functions, loops, data structures. If you've worked through something like Think Python, you're exactly the target reader.

What it doesn't assume is any prior knowledge of how the web works, what HTTP is, or what an API actually means beyond the buzzword.

How to use this book

Each chapter builds on the previous one. Read them in order, particularly Part I. The web-communication mental model matters — skipping it makes Part II harder than it needs to be.

Every chapter has:

  • → A clear learning objective
  • → Concept explanations with diagrams
  • → Working code examples
  • → Practice questions with reveal-able answers
  • → A checkpoint to test your understanding
🔵 A note on running code

Until Chapter 6 (Installing Requests), the examples won't run yet — we're building the mental model first. From Chapter 6 onward, every code block is meant to be run and experimented with.

Book structure

Part I — Understanding the Web gives you the mental model: clients, servers, HTTP, URLs, methods, status codes, and headers. No Python yet, just understanding.

Part II — The Requests Library is where we start writing code. You'll make real requests, handle responses, and deal with errors.

Part III — Working with APIs moves from theory to practice. You'll call real, live APIs and process the data they return.

Part IV — Projects puts it all together in three complete programs you build from scratch.
